# AI-Verse — Robot Index & Battle Arena

A cyberpunk-themed, browser-only interface demo featuring illustrated robot cards, model detail dialogs, and a scripted matchup arena.

## Features

- Robot cards grouped into Titan, Warrior, and Scout demo tiers
- Generated SVG robot illustrations with neon effects
- Model detail modal
- Two-fighter selection and scripted score-comparison simulation
- Demo Auto-Scan interaction that inserts a clearly labeled fictional placeholder
- Responsive layout and reduced-motion support

## Run locally

Open `index.html` in a modern browser. The page uses Tailwind CSS from its CDN and Google Fonts, so those external assets require an internet connection. No build step or API key is required.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Important data note

This is a visual/demo project, not a live AI-model directory or benchmark. Scores are illustrative values created for the interface. Some names and specifications are placeholders or historical examples and must not be treated as verified current model details. The battle result is determined by the demo score; it does not run, compare, or query AI models. Auto-Scan does not connect to providers or discover new models online.
